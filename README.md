# 🎮 Тетрис с Мультиплеером

Классический Тетрис с поддержкой мультиплеера в реальном времени через WebRTC (PeerJS).

## ✨ Возможности

### Одиночная игра
- Классический геймплей Тетрис
- 10 уровней сложности с нарастающей скоростью
- Система очков и очистка линий
- Анимации при стирании линий
- Адаптивный дизайн для ПК и мобильных

### Мультиплеер 🎮
- **Peer-to-Peer соединение** через WebRTC
- **Создание комнаты** с уникальным кодом
- **Присоединение по коду** к другу
- **Синхронизация в реальном времени**:
  - Счёт, уровень, линии
  - Состояние игрового поля
  - Следующая фигура
- **Десктопная версия**: полное поле противника + статистика
- **Мобильная версия**: компактная статистика противника
- **Экран победителя** с сравнением очков

## 🚀 Как играть в мультиплеер

### Шаг 1: Создание комнаты (Хост)
1. Нажмите кнопку **🎮 Мультиплеер** в правом верхнем углу
2. Выберите **🏠 Создать комнату**
3. Скопируйте код комнаты (например: `TETRIS-ABC12`)
4. Отправьте код другу
5. Дождитесь подключения игрока
6. Нажмите **Начать игру**

### Шаг 2: Присоединение к комнате
1. Нажмите кнопку **🎮 Мультиплеер**
2. Выберите **🔗 Присоединиться**
3. Введите код комнаты от хоста
4. Нажмите **Присоединиться**
5. Игра начнётся автоматически!

### Шаг 3: Игра
- Оба игрока играют одновременно
- Побеждает тот, кто:
  - Набрал больше очков, когда противник проиграл
  - Или продержался дольше

## 🎯 Управление

### Клавиатура (ПК)
- **← →** — Движение фигуры
- **↑** — Поворот
- **↓** — Ускорение падения
- **Пробел** — Мгновенный бросок
- **P / Esc** — Пауза

### Мобильные кнопки
- **↻** — Поворот
- **← → ↓** — Движение и ускорение
- **⏬** — Мгновенный бросок

## 📊 Система очков

- 1 линия = 100 × уровень
- 2 линии = 300 × уровень
- 3 линии = 500 × уровень
- 4 линии (Тетрис!) = 800 × уровень
- Бросок = +2 за каждую клетку падения

## 🗄️ Настройка Supabase для мультиплеера

### Шаг 1: Создайте таблицы в Supabase

1. Откройте [Supabase Dashboard](https://supabase.com/dashboard)
2. Выберите ваш проект
3. Перейдите в **SQL Editor**
4. Скопируйте содержимое файла `supabase-schema.sql` из корня проекта
5. Вставьте в SQL Editor и нажмите **Run**

### Шаг 2: Настройте переменные окружения

Создайте файл `.env.local` в корне проекта:

```env
VITE_SUPABASE_URL=https://ваш-проект.supabase.co
VITE_SUPABASE_ANON_KEY=ваш-anon-ключ
```

**Где найти ключи:**
1. В Supabase Dashboard → **Settings** → **API**
2. Скопируйте **Project URL** и **anon/public key**

### Шаг 3: Пересоберите проект

```bash
npm run build
```

Или если используете Vercel, просто задеплойте изменения.

## 📱 Тестирование мультиплеера

Для тестирования мультиплеера:
1. Откройте сайт на двух устройствах (или двух вкладках браузера)
2. На первом устройстве создайте комнату
3. Скопируйте код
4. На втором устройстве присоединитесь по коду
5. Играйте!

## 📝 Примечания

- Мультиплеер работает через **Supabase Realtime** (WebSocket)
- Бесплатный тариф Supabase: 500MB база, 2GB трафика, неограниченные Realtime соединения
- Для стабильного соединения рекомендуется хорошая интернет-связь
- Если возникают проблемы с подключением, проверьте правильность API ключей в `.env.local`
- Убедитесь, что выполнили SQL скрипт для создания таблиц в Supabase
